# 3.1.1

Ableton Extensions SDK / CLI を 1.0.0-beta.0 から 1.0.0-beta.1 へ更新したパッチリリース。公開 MCP ツールは `meta` / `do` / `render` / `undo` の 4 つで変更なし。機能コードの変更はない。

## 変更内容

### SDK / CLI の更新

- `apps/extension` の `@ableton-extensions/sdk` と `@ableton-extensions/cli` を `ableton-sdk/` 配下の 1.0.0-beta.1 tarball 参照へ変更した。上流の `upgrade.md` は vendor ディレクトリの差し替えと package.json の参照更新のみを指示しており、本リポジトリでは配布物を `ableton-sdk/`（`.gitignore` 対象）に置く構成へ読み替えている。
- beta.1 では次のゲッターに `Number()` 変換が入り、低レベル `HostApi` の `bigint` が高レベル API の境界で数値へ正規化される。beta.0 ではこの変換が無く、`JSON.stringify` を通る応答で `Do not know how to serialize a BigInt` が発生し得た（#144）。
  - `Clip.color`（`clipGetColor: (handle) => bigint`）
  - `Song.rootNote`（`songGetRootNote: (handle) => bigint`）
  - `Song.scaleIntervals`（`songGetScaleIntervals: (handle) => bigint[]`）
  - `DrumChain.receivingNote`（`drumchainGetReceivingNote: (handle) => bigint`）
- `Track.insertDevice(deviceName: string, index: number)` と `Chain.insertDevice(deviceName: string, index: number)` が公開された。本版では未使用で、書き込み表面への追加は #143 で扱う。

### Node.js の要求バージョン

- beta.1 の `package.json` が `node >= 24.16.0` を要求するため、リポジトリルートの `engines.node` を `>=24.14.1` から `>=24.16.0` へ引き上げた。

### ドキュメント

- README・`llm/ARCHITECTURE.md`・`llm/device-catalog.md` の SDK バージョン参照を beta.1 へ更新した。undo / redo API、Browser（デバイス列挙）API、選択状態の読み書き API、トラック並べ替え API は beta.1 にも無く、既存の代替と scope 縮小はそのまま維持する。
- `llm/midi-audition.md` に、beta.1 でも `Resources` の公開メソッドが `importAudioFile` と `renderPreFxAudio` のままであることを追記した。

## 動作確認

- `pnpm install`: 成功（`ableton-sdk/` に beta.1 の tarball を配置した状態）
- `pnpm typecheck`: 6 パッケージ成功。beta.0 から beta.1 への型差分による修正は不要だった
- `pnpm test`: 13 ファイル 82 件成功（`apps/extension`）、リポジトリ全体で 3 タスク成功
- `pnpm build`: 成功（`dist/extension.js` 2.5MB）

## 制約

- 実機（Live + Extension Host）での確認は未実施。beta.1 の `.ablx` を用いた検証は #107 で扱う。
- 開発環境の Node.js が 24.16.0 未満の場合、`pnpm install` は `Unsupported engine` の警告を出す（インストール自体は完了する）。
- `ableton-sdk/` は上流提供物のため `.gitignore` 対象であり、リポジトリのクローンだけでは `pnpm install` が通らない。beta.1 の zip から `ableton-extensions-sdk-1.0.0-beta.1.tgz` と `ableton-extensions-cli-1.0.0-beta.1.tgz` を `ableton-sdk/` へ配置する必要がある。

## インストール / 更新

- `pnpm package` で `apps/extension/dist/live-connector-3.1.1.ablx` を生成する。Live の Preferences → Extensions から読み込み、Live を再起動する。
- 3.1.0 からの移行手順は無い。設定・保存データの形式は変更していない。
