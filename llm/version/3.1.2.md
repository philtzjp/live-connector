# 3.1.2

`bigint` を含む値の JSON 直列化で `TypeError: Do not know how to serialize a BigInt` が発生する欠陥を修正したパッチリリース。公開 MCP ツールは `meta` / `do` / `render` / `undo` の 4 つで変更なし。

## 変更内容

### `packages/json`（新規）

JSON 直列化を集約するパッケージを追加した。応答・ログ・永続化の直列化はすべてこのパッケージを経由する。

- `bigintToJsonValue(value: bigint): number | string` — 安全整数の範囲内は `number`、範囲外は精度を落とさないよう 10 進文字列を返す。値を丸めたり既定値へ置き換えたりしない。
- `jsonReplacer(key, value)` — `JSON.stringify` の replacer。`bigint` のみを変換する。
- `stringifyJson(value, space?)` — 上記 replacer を適用した `JSON.stringify`。

### 直列化経路の集約

`JSON.stringify` の直接呼び出しを `stringifyJson` へ置き換えた。

- `apps/extension/src/tools/common.ts` の `textResult`（MCP ツール応答。`preview` の応答を含む）
- `apps/extension/src/server/http.ts` の `writeJson` / `writeProblem`（`/health` と RFC 9457 problem+json）
- `apps/extension/src/undo/log.ts`（undo ログの JSONL 追記とローテーション書き出し）
- `packages/log/src/index.ts` の `formatLine`（構造化ログフィールド）

### `bigint` プロパティの読み取り

`LomGraphAdapter.getProperty` は `string` / `number` / `boolean` / `null` 以外を `null` へ落としていたため、SDK が `bigint` を返すプロパティは値そのものが失われていた（`RETURN s.rootNote` が `null` になる）。`bigintToJsonValue` と同じ規則で数値へ正規化するよう変更した。

### コードルール

`AGENTS.md` のコードルールに「JSON 直列化は `packages/json` に集約する。応答・ログ・永続化の出力で `JSON.stringify` を直接呼ばない」を追加した（ルール 9、以降を繰り下げ）。

## 動作確認

- `pnpm typecheck`: 7 タスク成功
- `pnpm test`: 4 タスク成功。`packages/json` 9 件、`apps/extension` 87 件（`do.test.ts` に `preview bigint serialization` の 5 件を追加）
- `pnpm lint`: Biome 成功（116 ファイル）
- `pnpm build`: 成功

追加した回帰テストは、SDK 1.0.0-beta.0 が `Clip.color` / `Song.rootNote` / `Scene.tempo` を `bigint` で返していた状態を fixture で模し、次を検証する。

- `SET c.notes = [...]` の `preview` が `status:"preview"` を返し、`targets[].color` が数値である
- Scene の `COPY` の `preview` が `status:"preview"` を返し、`targets[].tempo` と `index` が数値である
- Scene の `DELETE` の `preview` が `status:"preview"` と `undoable:"full"` を返す
- ノードを返す読み取り（`RETURN s`）で `bigint` が数値として返る
- プロパティを返す読み取り（`RETURN s.rootNote`）で `bigint` が `null` にならない

## 制約

- 実機（Live + Extension Host）での確認は未実施。#107 で扱う。
- 安全整数の範囲を超える `bigint`（`Handle.id` が大きくなった場合など）は 10 進文字列として出力される。数値として扱う前提のクライアントは型を確認する必要がある。
- 循環参照を含む値の直列化は従来どおり `TypeError` を投げる。本版の対象外。
